# Configs

Verified, non-obvious configuration files from the reference server, grouped by component. Each file starts with a
comment that says **where to install it** and which guide explains it (except JSON, which can't have comments; see
the table).

| File | Install to | Guide |
|------|-----------|-------|
| [`apt/52unattended-upgrades-local`](apt/52unattended-upgrades-local) | `/etc/apt/apt.conf.d/` | [04, updates](../docs/04-base-setup.md#2-updates) |
| [`avahi/avahi-daemon.conf.changes`](avahi/avahi-daemon.conf.changes) | keys in `/etc/avahi/avahi-daemon.conf` | [03, avahi](../docs/03-ubuntu-install.md#avahi-settings) |
| [`docker/daemon.json`](docker/daemon.json) | `/etc/docker/daemon.json` | [05, daemon settings](../docs/05-docker.md#2-daemon-settings) |
| [`fstab/backup-drive.fstab`](fstab/backup-drive.fstab) | append to `/etc/fstab` | [07, backup drive](../docs/07-backups.md#1-backup-drive) |
| [`netplan/00-installer-config.yaml`](netplan/00-installer-config.yaml) | `/etc/netplan/` | [03, network](../docs/03-ubuntu-install.md#9-network-optional-interfaces-and-wi-fi-readiness) |
| [`sysctl/90-panic-reboot.conf`](sysctl/90-panic-reboot.conf) | `/etc/sysctl.d/` | [04, kernel panic](../docs/04-base-setup.md#6-reboot-on-kernel-panic) |
| [`systemd/journald-size.conf`](systemd/journald-size.conf) | `/etc/systemd/journald.conf.d/size.conf` | [04, journal](../docs/04-base-setup.md#8-cap-the-journal-size) |

**Security-sensitive settings** (firewall exceptions, fail2ban thresholds, SSH authentication) are deliberately
**not** mirrored here. See the principles in [security.md](security.md).

Values specific to one machine (MAC addresses, UUIDs, interface names) are placeholders marked `REPLACE`. Secrets
(e.g. the Wi-Fi password) are never stored here. Wi-Fi config is generated by
[`scripts/setup-wifi.sh`](../scripts/setup-wifi.sh).

Copy a file to the server, e.g.:

```bash
scp configs/sysctl/90-panic-reboot.conf homeserver:/tmp/ && ssh homeserver 'sudo install -m 644 /tmp/90-panic-reboot.conf /etc/sysctl.d/ && sudo sysctl --system'
```

The Docker Compose stack lives separately in [`stack/`](../stack/).
